# Yalda Embedding: Open Training and Benchmarking

Yalda Embedding is a 595.8-million-parameter Persian text embedding model built on
[Qwen3-Embedding-0.6B](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B).
The project introduces Yalda Embedding as the **first openly developed Persian embedding
model**, releasing its model weights, pairwise training data, precomputed teacher embeddings,
and the training and benchmarking notebooks collected here.

Yalda Embedding achieves **state-of-the-art performance among the evaluated models in the
0.6B parameter range**, with **competitive performance against the 4B Qwen3 embedding
model** on the paper's eight Persian retrieval tasks. These comparisons refer to the
reported evaluation suite, rather than all embedding models or tasks.

## Model and datasets

- [Yalda Embedding model](https://huggingface.co/Yaldat/Yalda-Embedding)
- [Persian pairwise dataset](https://huggingface.co/datasets/Yaldat/Persian-Pairwise)
- [Teacher-embedded pairwise dataset](https://huggingface.co/datasets/Yaldat/Persian-Pairwise-Embedded)
- [F2LLM-v2-8B teacher](https://huggingface.co/codefuse-ai/F2LLM-v2-8B)

The training collection contains **1,035,981 Persian query-positive-document pairs** from
13 retrieval resources. Teacher embeddings are precomputed offline; the 8B teacher does
not need to be loaded during student training or inference.

## Reported retrieval performance

The following values are the updated paper's unweighted macro-averages over eight Persian
retrieval tasks from FaMTEB. The final model is Ablation 6, trained with `KD_ALPHA = 0.75`.
They are reference results, not outputs generated by the cleaned notebooks.

| Model | Mean retrieval score |
| --- | ---: |
| Qwen3-Embedding-4B | 0.5563 |
| **Yalda Embedding** | **0.5488** |
| F2LLM-v2-0.6B | 0.5063 |
| Dibachain/Diba-Embed | 0.4788 |
| Qwen3-Embedding-0.6B | 0.4713 |
| heydariAI/persian-embeddings | 0.4175 |
| Tooka-SBERT-V2-Large | 0.4150 |

Yalda improves over its Qwen3-0.6B initialization by **0.0775 absolute**, approximately
**16.4% relative**, and over F2LLM-v2-0.6B by **0.0425 absolute**. It outperforms both on
all eight tasks at the reported precision. Against Diba-Embed, the gain is **0.0700 absolute**
(approximately **14.6% relative**), with higher scores on all eight tasks.

Against Qwen3-Embedding-4B, Yalda scores higher on NFCorpus-Fa, SynPerQARetrieval,
PersianWebDocumentRetrieval, and HotpotQA-FaHardNegatives, and ties on FiQA2018-Fa at the
reported precision. Its overall mean is **0.0075 below** the 4B reference.

On the three hard-negative evaluation tasks, Yalda scores **0.58** on HotpotQA,
**0.65** on MSMARCO, and **0.43** on NQ. Student training uses in-batch negatives and
relational distillation without explicitly mined or supplied hard negatives.

## Training

Open `Yalda-Embedding-Training.ipynb` on a TPU runtime with internet access and run the cells
in order. The paper uses **eight TPU v5e devices**. The notebook retains these installation
commands:

```python
!pip install -U "jax[tpu]==0.9.2" -f https://storage.googleapis.com/jax-releases/libtpu_releases.html
!pip install flax==0.12.6
```

Edit the configuration cell before running:

| Setting | Default | Meaning |
| --- | --- | --- |
| `KD_ALPHA` | `0.50` | Weight of relational knowledge distillation; set to `0.75` for the updated paper's final model. |
| `HF_TOKEN` | Read from the environment | Hugging Face authentication token. |
| `PUSH_REPO_ID` | `Yaldat/Yalda-Embedding` | Destination Hugging Face model repository. |
| `UPLOAD_TO_HUB` | `False` | Enable the final cell to publish exported weights. |
| `OUTPUT_DIR` | `yalda_embedding_export` | Local checkpoint, configuration, and training logs. |
| `SHUFFLE_SEED` | `None` | Optional data-shuffle seed; unset to match the paper's final setup. |

The notebook's current default `KD_ALPHA = 0.50` corresponds to Ablation 5 (mean **0.5313**).
To reproduce the updated paper's final configuration, set **`KD_ALPHA = 0.75`** before
training. This is Ablation 6 (mean **0.5488**), an improvement of **0.0175** over Ablation 5.

The objective is:

```text
loss = (1 - KD_ALPHA) * InfoNCE + KD_ALPHA * KL(teacher || student)
```

For the updated paper's final configuration, this becomes `0.25 * InfoNCE + 0.75 * KL`.

Both student and teacher embeddings are L2-normalized. Teacher vectors retain their first
1,024 Matryoshka dimensions. Distillation matches each query's distribution over the
documents in the global batch, rather than directly matching embedding coordinates.

| Training setting | Value |
| --- | --- |
| Backbone | Qwen3-Embedding-0.6B |
| Epochs | 1 |
| Global batch size | 512 |
| Maximum input length | 512 tokens |
| Peak learning rate | 2e-5 |
| Optimizer | AdamW |
| Warmup / decay | 10% linear warmup, then cosine decay |
| Gradient clipping | Global norm 1.0 |
| Student / teacher temperature | 0.05 / 0.07 |
| Final paper KD weight | 0.75 |
| Precision | BF16 projections with FP32 parameters, normalization, and losses |
| Distributed execution | Single-axis parameter and minibatch sharding |

Queries receive the fixed instruction `Given a web search query, retrieve relevant passages
that answer the query`; documents receive no instruction. Inputs use left padding and
last non-padding token pooling. With the reported dataset size, one epoch gives 2,023
updates; the final incomplete batch of 205 examples is omitted.

The export cell writes FP32 `model.safetensors` alongside the inherited tokenizer and
model configuration. The output directory also includes `training_config.json`,
`training_history.json`, and `training_loss_curve.png`. The configuration log excludes
the authentication token. Publishing weights uses the **Hugging Face Hub**;
`PUSH_REPO_ID` is not a GitHub repository setting.

## Benchmarking

Open `Benchmark.ipynb` on a GPU runtime with internet access. Set `MODEL_ID` to Yalda or
another Sentence Transformers-compatible model, then choose `TASK_NAMES`.
The default selection is `HotpotQA-FaHardNegatives`. To run all eight tasks, set:

```python
TASK_NAMES = ALL_TASK_NAMES.copy()
```

The available suite is:

1. `FiQA2018-Fa`
2. `NFCorpus-Fa`
3. `SynPerQARetrieval`
4. `PersianWebDocumentRetrieval`
5. `HotpotQA-FaHardNegatives`
6. `MSMARCO-FaHardNegatives`
7. `NQ-FaHardNegatives`
8. `SciFact-Fa`

The benchmark uses **test splits**, FP16 model loading, a maximum input length of **512**,
and an encoding batch size of **64**. Prompt and pooling behavior come from the loaded
model and MTEB's integration; the notebook does not force a common query instruction.
It prints dependency versions and the full returned results. MTEB remains unpinned,
matching the original benchmark installation. Record the installed versions, model
revision, and exact score field with each run when reproducing or comparing results.

## Authentication

Use the runtime's secrets or environment to supply `HF_TOKEN`; the notebooks contain no
embedded credentials. A token is required for uploading to a repository you can write to.
Public model and dataset downloads usually do not require authentication. Clear any
locally entered token and notebook outputs before sharing.
